# kata-posta-order

**Kata 75 per l'especialitat fullstackPHP 8-4-26**

Imagina't que fas cua a una oficina de correus i demanes torn.

Els torns tenen 5 tipus:

- C (Cita prèvia)
- E (Enviament)
- R (Recollida) 
- O (Altres tràmits)
- I (Informació)

I també tenen un número correlatiu, de tal forma que es mostren com a expressions del tipus:

C024  

E001  

C025  

R123  


És important que els números siguin correlatius per cada codi de torn diferent, ja que indiquen un ordre.

Crea una estructura que representi aquesta informació i:
- Crea una lògica que permeti crear un nou torn.
- Crea una altra lògica que permeti "cridar" a la persona que té aquest torn. 
- A més, crea una altra lògica que permeti eliminar aquest torn ja realitzat.
